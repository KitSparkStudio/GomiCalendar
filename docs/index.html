コア機能

全国 1,400+ 市区町村

47 都道府県・全市区町村カタログから検索。主要都市は詳細カレンダー、その他は標準テンプレートで曜日を調整できます。

現在地から即カレンダー

GPS＋日本語住所解析（ja_JP）で都道府県・市区町村を自動マッチ。IP ずれに頼らない、ワンタップ設定。

収集日カスタム

町丁目やマンション規定と違う場合も、「収集日カスタム」で周期・臨時日を自由に上書き。ホームとウィジェットへ即反映。

ウィジェット＆ライブアクティビティ

ホーム画面の基本ウィジェットは無料。Pro（¥480 買い切り）で多地区管理、中サイズ／ロック画面ウィジェット、テーマ拡張、そしてダイナミックアイランド＆ロック画面のリアルタイム締切カウントダウン（Dynamic Island Live Countdown）を永久解放します。

使い方（かんたん 3 ステップ）

1. 地区を決める

「現在地から自動設定」を押すか、都道府県 → 市区町村を検索。見つからない場合は手動入力も可能です。

2. 収集日を合わせる

掲示板や自治体案内と違う日があれば「収集日カスタム」で修正。テンプレート地区は可燃曜日の調整も無料です。

3. リマインドを置く

通知と基本ウィジェットで出し忘れを防止。対応機種のダイナミックアイランド Live Countdown は Pro で利用可能。粗大ごみの予約メモも同梱。

Pro で広がる使い方（¥480 買い切り）

一度の購入で永久解放：① 多地区管理（自宅＋会社／家族）② 中サイズ／ロック画面ウィジェット ③ カスタムテーマカラー ④ ダイナミックアイランド＆ロック画面のリアルタイムカウントダウン（Dynamic Island Live Countdown）。サブスクリプションはありません。

1. 位置情報はどのように使われますか？

市区町村の収集ルールをその場でマッチするためだけに、現在地を一度取得します。位置の履歴保存・追跡・第三者提供はありません。

2. 無料と Pro の違いは？

収集カレンダー・収集日カスタム・粗大ごみツール・基本リマインダーは無料。Pro（¥480 買い切り）は次を永久解放します：多地区管理、中サイズ／ロック画面ウィジェット、カスタムテーマ、ダイナミックアイランド＆ロック画面のリアルタイム締切カウントダウン（Dynamic Island Live Countdown）。サブスクリプションはありません。

3. 購入を復元するには？

アプリ内の Pro 画面で「購入を復元」をタップしてください。Apple StoreKit が Apple ID の権利を確認します。

プライバシー（概要）

ゴミログはローカルファースト（Local-First）です。地区設定・カスタム収集日・メモは端末と、お客様個人の iCloud 同期領域にのみ保存され、業務サーバーへのアップロードや個人身元の追跡はありません。

  • 位置情報は市区町村マッチングの一瞬のみ。保存・追跡しません。
  • 広告・分析・トラッキング SDK は一切埋め込みません。個人識別データの収集はありません。
  • アプリ内課金は Apple StoreKit が処理し、決済情報は Apple が管理します。
